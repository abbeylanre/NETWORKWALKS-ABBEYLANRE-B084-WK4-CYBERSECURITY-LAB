## Project Overview
This repository documents my Week 4 practical activities as part of the **NetworkWalks Cybersecurity Internship**. 

The project focuses on conducting an authorized security assessment of a designated web application (`www.medirozahospital.com`), covering initial access, data extraction, controlled attack simulation, and structured penetration testing documentation.

## Project Objectives
- Understand the overall security posture of the target web application.
- Perform passive and active reconnaissance to identify publicly available information.
- Examine potential entry points and underlying security weaknesses.
- Conduct controlled security testing strictly within the approved scope.
- Document technical findings, observations, and supporting evidence.
- Develop a structured penetration testing report with actionable remediation recommendations.

> **Authorization Note:** All testing activities were conducted strictly within the scope and authorization provided by the project owner.

## Tools & Environment
**Operating System:** Kali Linux

**Reconnaissance & Inspection Tools:**
- **WHOIS** – Domain registration and ownership information gathering
- **WhatWeb** – Web server and technology stack identification
- **NSLookup** – DNS record and IP address resolution
- **cURL** – HTTP response header and HTML content inspection
- **Wafw00f** – Web Application Firewall (WAF) detection and fingerprinting
- **DNSRecon** – DNS enumeration and record discovery
